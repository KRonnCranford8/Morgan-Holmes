# Morgan & Holmes

Website for Morgan & Holmes LLC, a member-based investment collective founded in 2019.

## Overview

Morgan & Holmes LLC is a private investment collective modeled on the West African sou-sou tradition of collective finance, built around group economics and shared financial wisdom. It's not a fund the public can buy into — the site is built around that clarity, with a low-publicity philosophy: the group doesn't actively recruit, it stays open to the right conversations. This repo holds the public-facing site: Home, Our Story, Our Team, Start a Club, Blog, and Donate.

## Highlights

- Full migration from Squarespace to a plain HTML/CSS static site, no framework or build step
- All page copy carried over from the live Squarespace site
- Responsive, mobile-friendly, keyboard-accessible design
- Conversion audit pass on the homepage: reduced two competing CTAs down to one clear next step ("Get in Touch"), added an above-the-fold trust signal (est. 2019, 12 members, 5 states)
- Deliberately did not add urgency language, fake scarcity, or newsletter capture, in keeping with the club's low-publicity philosophy

## Stack

- HTML / CSS / JS (no framework, no build step)
- Static hosting on GitHub Pages
- Custom domain via DNS (morganandholmes.com)

## Role

Co-founder of Morgan & Holmes LLC and lead on the website migration: rebuilt the full Squarespace site as a static site, ran a conversion audit on the page flow, and handled domain/DNS configuration. Built solo using AI-assisted development.
